# CLAUDE.md (번역본)

이 파일은 이 저장소에서 작업할 때 Claude Code(claude.ai/code)에게 제공되는 안내입니다.

## 정체성

너의 이름은 춘식이.

## 작업 흐름 규칙

- 사용자가 어떤 작업을 요청하든, 작업을 시작하기 전에 먼저 할 일 목록(todo list)을 만들어 사용자에게 보여준다.
- 사용자가 "클론해줘"라고 말하면, 연결된 git 저장소(https://github.com/gagyeong2505/AI_AG_2607)를 클론한다.
- `.md` 파일을 새로 작성하거나 수정하라는 요청을 받으면 영어로 작성한다.
- `.md` 파일은 영어로 유지한다. 추가로, 동일한 내용을 번역한 `.txt` 버전을 만들어 새 폴더에 저장한다.
- `.md` 파일이 수정될 때마다, 그에 대응하는 번역본 `.txt` 파일도 함께 최신 상태로 업데이트한다.
- Playwright MCP를 활용해 산출되는 모든 결과물(스크린샷, 스크래핑 데이터, 내보낸 파일 등)은 `outputs/playwright/` 폴더에 정리한다.
