# Trivago 숙소 브리핑 (번역본)

**name:** trivago-accommodation-briefing
**description:** trivago MCP 도구(trivago-accommodation-search, trivago-accommodation-radius-search)를 이용해 숙소 가격을 비교하고, 최저가 순으로 정렬한 뒤 별점·게스트 리뷰 점수·리뷰 요약을 포함한 브리핑을 생성한다. 사용자가 호텔/숙소 검색·비교를 요청하거나, 특정 목적지·날짜의 최저가 숙소를 찾아달라고 하거나, "숙소 비교", "최저가 숙소", "호텔 브리핑" 등을 요청할 때 사용한다.

## 개요

목적지(또는 특정 장소)와 여행 날짜가 주어지면 trivago MCP 도구로 숙소를 검색하고, 결과를 가격이 낮은 순으로 정렬한 뒤, 각 가격에 별점과 게스트 리뷰 점수/하이라이트를 짝지은 브리핑을 만든다. 완성된 브리핑은 프로젝트의 `travel/` 폴더 아래에 Markdown 파일로 저장한다.

## 작업 흐름

### 1단계: 여행 요구사항 수집

어떤 도구도 호출하기 전에, 부족한 정보만 사용자에게 확인한다:
- 목적지 — 도시/지역명(`trivago-accommodation-search`용) 또는 좌표를 알 수 있는 특정 랜드마크/주소(`trivago-accommodation-radius-search`용)
- 도착일과 출발일 (`YYYY-MM-DD`, 도착일은 오늘 이후, 출발일은 도착일 이후)
- 성인 인원수(필수), 아동 인원수 및 나이(선택)
- 객실 수(선택, 성인 수 이하)
- 필수 조건: 최소 별점, 최소 게스트 리뷰 점수, 편의시설(조식, 무료 취소, 수영장 등), 예산 상한, 기본값(US/USD/EN_US)과 다른 통화/국가/언어

### 2단계: 검색 도구 선택 및 호출

- 사용자가 목적지 이름이나 관심 장소(`query`)를 제시하면 `mcp__trivago__trivago-accommodation-search`를 사용한다.
- 사용자가 특정 좌표나 정확한 랜드마크/주소(지오코딩하여 `latitude`/`longitude`로 변환)를 제시하면 `mcp__trivago__trivago-accommodation-radius-search`를 사용한다.

수집한 요구사항을 도구의 파라미터(`arrival`, `departure`, `adults`, `children`, `children_ages`, `rooms`, `filters`, `hotel_rating`, `review_rating`, `currency`, `country`, `language`)에 그대로 매핑한다. 사용자가 실제로 요청한 `hotel_rating`/`review_rating`/`filters` 플래그만 설정한다 — 모두 `false`로 두면 필터 없는 전체 결과가 반환되며, 이는 보통 전체 가격 비교에 적합하다.

### 3단계: 최저가 순 정렬

결과를 총액/1박 요금(도구가 반환하는 값 기준) 오름차순으로 정렬한다. 사용자가 목록 개수를 제한해 달라고 하지 않는 한 모든 결과를 유지하되, 결과가 많으면 기본적으로 가장 저렴한 상위 10개와 눈에 띄는 항목(예: 가격은 조금 더 비싸지만 리뷰 점수가 확연히 높은 경우)을 포함한다.

### 4단계: 브리핑 작성

정렬된 목록의 각 숙소에 대해 다음을 기록한다:
- 이름과 가격(통화 포함)
- 별점(호텔 등급)
- 게스트 리뷰 점수와, 제공된 경우 리뷰 개수
- 도구 결과에 포함되어 있다면 리뷰 하이라이트나 특징적인 편의시설 1~2개
- 최저가, 최고 평점, 또는 최고 가성비(가격 대비 리뷰 점수가 가장 높은) 항목이라면 짧게 표시

`templates/briefing_template.md`의 구조를 사용해 브리핑을 작성한다.

### 5단계: 브리핑을 `travel/`에 저장

완성된 브리핑을 프로젝트의 `travel/` 폴더(없으면 새로 생성)에 Markdown 파일로 저장한다. 파일명은 `travel/<목적지-슬러그>_<도착일>_briefing.md` 형식으로 한다(예: `travel/tokyo_2026-09-10_briefing.md`). 목적지는 소문자·공백은 하이픈으로 변환·구두점 제거 방식으로 슬러그화한다. 저장 후 사용자에게 파일 경로를 알리고, 상위 1~3개 추천을 채팅에 요약해 준다.

## 참고 사항

- 사용자가 파일 저장 없이 빠른 답변만 원하더라도, 이후 비교를 위해 남겨둘 수 있도록 `travel/`에는 계속 저장한다 — 사용자가 명시적으로 저장하지 말라고 하지 않는 한 5단계를 건너뛰지 않는다.
- trivago가 주어진 필터로 결과를 반환하지 않으면, 필터를 하나씩(편의시설 필터 먼저, 그다음 평점 기준) 완화하고 무엇을 완화했는지 사용자에게 알린다.
- 가격, 평점, 리뷰를 절대 임의로 지어내지 않는다 — 도구 호출 결과에 있는 내용만 보고한다.
